# Lindbergh Ultimate — Project & Portfolio IV

A full-stack website for the Lindbergh Ultimate frisbee program. The site
includes public program pages, media galleries, registration and interest
forms, and a single-administrator panel for managing site content.

## Project

- **Application:** [`dev/portfolio/`](./dev/portfolio/)
- **Frontend:** React 19, Vite 7, React Router 7, Tailwind CSS 4
- **API:** Node.js 20+, Express 5, Mongoose 9
- **Database:** MongoDB Atlas (or local MongoDB)
- **Admin Panel:** `/admin`
- **Figma prototype:** [Lindbergh Ultimate design](https://www.figma.com/site/TOze5vN2cIgcQ1yQXx25GB/Lindbergh-Ultimate?node-id=0-1&t=b5QKfFgOkyA7nLAw-1)
