# Welcome! ...🚀

This example repository contains general files and structure you can use when setting up your own repo for Project & Portfolio. Use this example to understand how to organize your research, development, and experimentation conducted in this class. Follow the instructions below to get started.

<br>

## Step 1

If you haven't already, create a new _private_ repo following this naming convention:

_Repository Naming Convention:_ **YYMM-WDV349-LastFirst**

- Replace "YYMM" with the year and month, and "LastFirst" with your last and first name

## Step 2

Go to your new repository settings tab, click "Collaborators", and then add your instructor(s) in this course so they have access to your repository. \*

- See the "Course Information" activity or _Instructor Profile_ for their GitHub account names. If a GitHub account name is missing, you can request their GitHub account name by reaching out to your instructor and requesting this by email.

## Step 3

Attend the first meeting. If you are unable to attend, be sure to watch the meeting archive video (see **The Week Ahead** activity).

<br>

### Next Steps...

As you complete the steps above, take some time to review this example. Feel free to copy the contents of this example (files and folders) into the new repo you create to quickly organize your work for this upcoming month. A few things to keep in mind...

- At the root level of your repository be sure to create a ".gitignore" file. An example is provided with this download.
- At the root level of your repository, feel free to copy the .github folder. This contains issue templates you're welcome to experiment with throughout this course.
- The main README you create for your own repo can initially look like the example text below. Replace "First Last" with your own first and last name.
