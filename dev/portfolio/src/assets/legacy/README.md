# Restored legacy photos

These files are the original coach and booster photos that were removed when the
app was consolidated into `dev/portfolio`. They are restored here as **unused
source assets** so the originals are not lost.

- The public site still uses anonymized placeholder avatars. No page imports
  these files.
- Filenames were changed to generic role names to avoid putting personal names
  in the repository.
- `coach-1.jpg` and `booster-5.jpg` were cropped to remove visible clipboard
  text/name labels.
- These are real people. Confirm consent and the intended use before publishing
  them or wiring them into the public site.
